# Agroconnect
## Configuración del entorno (Backend)
1. Clonar el repositorio (git clone __link del repositorio_)
2. Crear el entorno virtual de la raiz (python -m venv .venv)
3. Activar el entorno virtual (en Windows PowerShell: .venv\Scripts\Activate.ps1).
4. Instalar las dependencias (pip install -r backend/requirements.txt).
